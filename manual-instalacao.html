CODE ARENA / WINDOWS

Manual de instalação

Abra o aplicativo para estudar. Configure o executor quando quiser rodar os projetos das oficinas em Python.

O download ainda não está disponível nesta página. O botão será ativado quando o arquivo for publicado.

01. Abrir o Code Arena

A distribuição atual é um aplicativo portátil para Windows x64: o arquivo .exe abre o programa diretamente, sem assistente de instalação.

  1. Quando o download estiver disponível, salve o arquivo em uma pasta permanente, como Documentos → Code Arena. Se receber um ZIP, extraia os arquivos antes de abrir.
  2. Abra o arquivo .exe do Code Arena.
  3. Se o Windows informar que falta o WebView2, instale o WebView2 Runtime da Microsoft, opção Evergreen, e abra o Code Arena novamente.

Você pode estudar as aulas e usar os exercícios com simulador sem instalar Docker. Para executar Python nas oficinas, siga a próxima etapa.

02. Preparar as oficinas Python

Você precisa do pacote de execução do Code Arena, além do .exe. Ele contém o atalho Preparar e iniciar Python.cmd. Se recebeu apenas o aplicativo, solicite também esse pacote ao N7 Studio.

  1. Instale o Node.js LTS para Windows, incluindo o npm.
  2. Instale o Docker Desktop para Windows. Siga os requisitos oficiais de Windows, WSL 2 e virtualização indicados nessa página e use contêineres Linux.
  3. Abra o Docker Desktop e aguarde a indicação Engine running.
  4. Extraia o pacote de execução e abra Preparar e iniciar Python.cmd. A primeira preparação precisa de internet: o atalho instala as dependências, prepara o ambiente Python e executa as verificações.
  5. Quando o serviço estiver pronto, abra Oficina Python → Laboratório Python no aplicativo. Cole o token exibido na janela do serviço e clique em Conectar executor.

Mantenha o Docker e a janela do serviço abertos durante as oficinas. Ao reiniciar o serviço, conecte novamente com o novo token. Para encerrar o serviço, pressione Ctrl+C na janela dele.

Não é necessário instalar Python separadamente: o executor prepara o ambiente dentro do Docker. Rust, Git e ferramentas de compilação também não são necessários para abrir o aplicativo.

03. Guardar seu progresso

O estudo fica salvo no dispositivo. Para usar a nuvem, abra Conta e nuvem, entre com Google e confira a primeira sincronização. Se aparecerem versões diferentes de notas ou rascunhos, revise as opções antes de confirmar.

Use Backup completo antes de trocar de computador ou substituir sua cópia do aplicativo. Guarde esse arquivo em uma pasta sua.

Se algo não funcionar

O aplicativo não abre
Confira o WebView2 e se o arquivo foi extraído do ZIP. Se o Windows bloquear a execução, anote a mensagem e envie ao suporte.
O executor não conecta
Confirme que o Docker está em execução e que a janela do serviço continua aberta. Copie o token atual; ele muda quando o serviço reinicia.
O atalho parou durante a preparação
Leia a última mensagem da janela. Confira a conexão com a internet e se Node.js e Docker foram instalados. Feche outra instância do serviço antes de tentar novamente.
