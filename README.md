# UNIO Code — site

Site publicado em https://www.nsectech.com.br/ pelo repositório normanff/Nsec e Vercel. HTML, CSS, JavaScript e esbuild.

## Desenvolvimento

Node.js 20+. Execute npm ci, npm run build, npm test e npm run preview. Prévia em http://127.0.0.1:4181. Build somente em dist.

## Marca e documentação

Mantido somente o nome UNIO Code. Restaurado o visual branco com faixa coral e detalhes em laranja queimado. Fonte Inter hospedada localmente sob SIL OFL (assets/Inter-LICENSE.txt). Veja IDENTIDADE-VISUAL.md e manual-instalacao.html.

O aplicativo beta 23 ainda pode exibir Code Arena. Arquivos internos, executável e dados não foram renomeados. Captura real preservada, sem legenda sobreposta. Download desativado; manual disponível.

## Interação e verificações

Faixa com rolagem contínua sem botão, conforme solicitado, estática sem JavaScript ou com movimento reduzido. Menu responsivo, recursos expansíveis e contato por rascunho de e-mail. Nenhuma mensagem é enviada automaticamente. Contato: normanff57@gmail.com.

Testes de build, arquivos, IDs, âncoras e scripts via npm test. Conferir também navegação, formulário, manual, responsividade e animação no navegador. Não publicar scripts locais de edição nem node_modules.

Menu com indicador de colchetes deslizante no desktop e painel de abertura escalonada no celular. Suporta foco, Escape, clique externo, seção ativa, redimensionamento e movimento reduzido.

Refinamento atual: rótulos abaixo da captura removidos, travessões retirados da interface, setas nos recursos expansíveis e laranja queimado #C2410C. Indicador do menu com expansão direcional e acomodação suave, respeitando movimento reduzido.
