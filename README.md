# UNIO Code — site

Site publicado em https://www.nsectech.com.br/ pelo repositório normanff/Nsec e Vercel. HTML, CSS, JavaScript e esbuild.

## Desenvolvimento

Node.js 20+. Execute npm ci, npm run build, npm test e npm run preview. Prévia em http://127.0.0.1:4181. Build somente em dist.

## Marca e interface

O site usa o símbolo U da edição desktop, a foto da bancada e a fonte Inter hospedada localmente. A galeria reúne capturas da Beta 2.0.0 em WebP. Os arquivos estão em `assets/`. Consulte [a identidade visual](IDENTIDADE-VISUAL.md).

O manual de instalação está disponível e o download público permanece desativado. O desafio Codinome Nova confere a escolha no navegador. O suporte abre o aplicativo de e-mail do visitante. As páginas sobre a NSEC Tech, privacidade e termos de uso ficam acessíveis no rodapé de todas as páginas.

Os pedidos de aviso chegam a suporte@nsectech.com.br com o assunto “Aviso de lançamento do UNIO Code”. Ao abrir o download, a equipe deve responder individualmente aos interessados, deduplicar remetentes e excluir da fila quem pediu cancelamento. O site não dispara e-mails automaticamente.
