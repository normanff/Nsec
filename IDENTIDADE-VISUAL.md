# UNIO Code — padrão atual do site

UNIO Code é o novo nome do Code Arena. Por decisão do responsável, somente o nome da proposta de identidade foi mantido.

O site conserva o visual editorial anterior: fundo branco, título preto em Inter de peso regular, etiquetas cinza, botões laranja queimado (#C2410C) e faixa coral (#FF454B) com rolagem automática sem botão. Movimento reduzido exibe a faixa estática. O símbolo infinito e a paleta preta/vermelha foram retirados.

Python Academy, desafios de código, Battle Time e Conta e nuvem continuam com as denominações funcionais existentes. UNIO Learn, UNIO Arena e UNIO Cloud não são usados nesta versão do site.

O manual explica a correspondência com Code Arena na beta 23. A captura é autêntica; sua legenda visual foi removida a pedido. O executável e os dados do aluno não foram renomeados. Baixar UNIO Code permanece desativado.

Refinamento atual: rótulos abaixo da captura removidos, travessões retirados da interface, setas nos recursos expansíveis e laranja queimado #C2410C. Indicador do menu com expansão direcional e acomodação suave, respeitando movimento reduzido.
