# UNIO Code — identidade visual

Referência: painel de identidade fornecido pelo responsável pelo produto em 12 de novembro de 2026.

## Nome e arquitetura

**UNIO Code** é a marca principal, anteriormente N7 Code Arena / Code Arena. Assinatura: **Aprenda · Pratique · Evolua**.

| Marca | Uso no site | Correspondência na beta atual |
| --- | --- | --- |
| UNIO Learn | Cursos e trilhas | Python Academy |
| UNIO Arena | Desafios e prática | Code Arena e Battle Time |
| UNIO Cloud | Continuidade e sincronização do estudo | Conta e nuvem |

Os nomes organizam a apresentação da plataforma. Não anunciam novos serviços disponíveis: competições online 1v1 seguem futuras; UNIO Cloud não significa hospedagem de aplicações ou armazenamento irrestrito.

## Cores

| Cor | Código | Aplicação |
| --- | --- | --- |
| Vermelho principal | `#E10600` | Ações, detalhes do símbolo, bordas de destaque |
| Vermelho profundo | `#7A0000` | Faixa animada, seleção, fundos de destaque |
| Preto | `#0B0B0B` | Fundo principal |
| Grafite | `#1A1A1A` | Painéis e campos |
| Cinza escuro | `#2E2E2E` | Estados de interação e divisórias discretas |
| Prata | `#C9C9C9` | Texto secundário e símbolo |

Complementos funcionais: `#F5F5F5` para texto principal, `#454545` para bordas, `#FF625C` e `#FF7872` para pequenos detalhes e foco legíveis no fundo escuro. Não usar vermelho principal em parágrafos pequenos sobre preto.

## Tipografia e símbolo

Inter variável, hospedada no site sob SIL OFL; licença em `assets/Inter-LICENSE.txt`. Pesos de 400 a 750 na interface. Títulos sem itálico; textos auxiliares com pelo menos 14px.

O símbolo de infinito foi adaptado em SVG para cabeçalho, rodapé e favicon. É uma versão vetorial simplificada para telas pequenas, inspirada no metal e vermelho do painel, não uma reprodução 3D do original. Não distorcer suas proporções. O nome deve permanecer legível como UNIO Code.

## Transição e conteúdo

Esta entrega altera o site e sua documentação. O executável, os identificadores de autenticação, os dados do aluno e os serviços não são renomeados. Na beta 23, nomes antigos ainda podem aparecer; o manual explica essa correspondência.

A captura de tela continua autêntica e é identificada como anterior à nova marca. Não editar a captura para simular um aplicativo já atualizado. O botão Baixar UNIO Code continua desativado até a disponibilização do arquivo.

## Movimento

Faixa horizontal contínua sem botão, conforme preferência do responsável. Sem JavaScript e com `prefers-reduced-motion: reduce`, exibir conteúdo estático. Duplicação visual deve permanecer oculta de leitores de tela. Não adicionar flashes ou pulsos vermelhos.
