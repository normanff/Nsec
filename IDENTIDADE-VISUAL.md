# UNIO Code — padrão atual do site

UNIO Code é o novo nome do Code Arena. Por decisão do responsável, somente o nome da proposta de identidade foi mantido.

O site conserva o visual editorial anterior: fundo branco, título preto em Inter de peso regular, etiquetas cinza, botões roxos (#673DE6) e faixa coral (#FF454B) com rolagem automática sem botão. Movimento reduzido exibe a faixa estática. O símbolo infinito e a paleta preta/vermelha foram retirados.

Python Academy, desafios de código, Battle Time e Conta e nuvem continuam com as denominações funcionais existentes. UNIO Learn, UNIO Arena e UNIO Cloud não são usados nesta versão do site.

O manual explica a correspondência com Code Arena na beta 23. A captura é autêntica e identificada como anterior ao novo nome. O executável e os dados do aluno não foram renomeados. Baixar UNIO Code permanece desativado.
